# ASR/LLM/TTS 统一服务优化改进方案

## 📋 当前架构分析

### 现有架构概览

你的系统采用微服务架构，通过 Docker Compose 部署三个独立的语音服务（ASR、Qwen-TTS、CosyVoice）和一个独立的 LLM WebSocket bridge，使用 Nginx 作为统一网关。

```
客户端 → Nginx TLS Gateway (18443)
         ├─→ /asr/v1/realtime → ASR 服务 (内置 VAD)
         ├─→ /tts/v1/realtime → Qwen-TTS 服务
         ├─→ /tts/cosyvoice → CosyVoice 服务
         └─→ /ws/v1/chat/completions → LLM WSS Bridge (独立运行在 18444)
```

### 架构优势
- ✅ 服务隔离清晰，易于独立扩展
- ✅ 使用 OpenAI 兼容协议，易于替换底层模型
- ✅ 统一的 Bearer Token 认证
- ✅ 内置并发控制和资源限流

### 当前存在的问题

#### 1. **认证机制分散**
- ASR/TTS 服务共享 `WSS_API_KEY`
- LLM 服务使用独立的 `WSS_API_KEY`
- 缺少用户级别的认证和权限管理
- 无法追踪单个用户的使用情况

#### 2. **推理架构不统一**
- ASR/TTS 使用 Protocol 接口 + Backend 工厂模式
- LLM 使用简单的 HTTP 代理模式
- 每个服务独立管理连接池和超时
- 缺少统一的错误处理和重试机制

#### 3. **配置管理复杂**
- 环境变量数量多（50+ 个配置项）
- 三个服务的配置分散在 docker-compose.yml 中
- 缺少配置验证和默认值管理
- 难以在运行时动态调整配置

#### 4. **监控和可观测性不足**
- 只有简单的 `/healthz` 健康检查
- 缺少请求追踪和日志关联
- 没有性能指标（延迟、吞吐量、错误率）
- 无法监控底层模型服务的状态

#### 5. **部署和运维复杂**
- 多个服务需要独立启停
- 缺少统一的日志收集
- 没有自动化的故障恢复
- 扩容需要手动调整多个配置

```python
from __future__ import annotations

import asyncio
import time
from contextlib import asynccontextmanager
from dataclasses import dataclass
from typing import Optional

from fastapi import FastAPI, WebSocket, Request, HTTPException
from fastapi.responses import JSONResponse
import httpx
import jwt
from redis import asyncio as aioredis

@dataclass
class GatewayConfig:
    """统一网关配置"""
    jwt_secret: str
    jwt_algorithm: str = "HS256"
    redis_url: str = "redis://localhost:6379"
    
    # 后端服务地址
    asr_service_url: str = "http://asr:8000"
    qwen_tts_service_url: str = "http://qwen-tts:8000"
    cosyvoice_service_url: str = "http://cosyvoice:8000"
    llm_service_url: str = "http://llm-wss:8000"
    
    # 限流配置
    rate_limit_requests: int = 100
    rate_limit_window: int = 60  # seconds
    
    # 超时配置
    websocket_timeout: float = 300.0
    http_timeout: float = 30.0


class TokenManager:
    """JWT Token 管理器"""
    
    def __init__(self, secret: str, algorithm: str = "HS256"):
        self.secret = secret
        self.algorithm = algorithm
    
    def verify_token(self, token: str) -> dict:
        """验证并解析 JWT token"""
        try:
            payload = jwt.decode(token, self.secret, algorithms=[self.algorithm])
            return {
                "user_id": payload.get("user_id"),
                "tenant_id": payload.get("tenant_id"),
                "scopes": payload.get("scopes", []),
                "exp": payload.get("exp")
            }
        except jwt.ExpiredSignatureError:
            raise HTTPException(status_code=401, detail="Token expired")
        except jwt.InvalidTokenError:
            raise HTTPException(status_code=401, detail="Invalid token")
    
    def create_token(self, user_id: str, tenant_id: str, scopes: list[str], 
                    expires_in: int = 3600) -> str:
        """创建 JWT token"""
        payload = {
            "user_id": user_id,
            "tenant_id": tenant_id,
            "scopes": scopes,
            "exp": time.time() + expires_in,
            "iat": time.time()
        }
        return jwt.encode(payload, self.secret, algorithm=self.algorithm)


class RateLimiter:
    """基于 Redis 的分布式限流器"""
    
    def __init__(self, redis: aioredis.Redis):
        self.redis = redis
    
    async def check_rate_limit(self, key: str, max_requests: int, 
                              window: int) -> bool:
        """检查是否超过限流"""
        current = await self.redis.incr(key)
        if current == 1:
            await self.redis.expire(key, window)
        return current <= max_requests
    
    async def get_remaining(self, key: str, max_requests: int) -> int:
        """获取剩余请求次数"""
        current = await self.redis.get(key)
        if current is None:
            return max_requests
        return max(0, max_requests - int(current))


class MetricsCollector:
    """指标收集器"""
    
    def __init__(self):
        self.request_count = {}
        self.request_duration = {}
        self.error_count = {}
    
    def record_request(self, service: str, path: str, duration: float, 
                      status: str):
        """记录请求指标"""
        key = f"{service}:{path}"
        if key not in self.request_count:
            self.request_count[key] = 0
            self.request_duration[key] = []
            self.error_count[key] = 0
        
        self.request_count[key] += 1
        self.request_duration[key].append(duration)
        if status == "error":
            self.error_count[key] += 1


def create_gateway_app(config: GatewayConfig) -> FastAPI:
    """创建统一网关应用"""
    
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        # 初始化 Redis 连接
        app.state.redis = await aioredis.from_url(config.redis_url)
        app.state.http_client = httpx.AsyncClient(
            timeout=httpx.Timeout(config.http_timeout)
        )
        app.state.token_manager = TokenManager(config.jwt_secret)
        app.state.rate_limiter = RateLimiter(app.state.redis)
        app.state.metrics = MetricsCollector()
        
        try:
            yield
        finally:
            await app.state.redis.close()
            await app.state.http_client.aclose()
    
    app = FastAPI(
        title="Unified Speech Services Gateway",
        lifespan=lifespan
    )
    
    @app.middleware("http")
    async def auth_and_metrics_middleware(request: Request, call_next):
        """认证和指标中间件"""
        start_time = time.time()
        
        # 跳过健康检查
        if request.url.path == "/healthz":
            return await call_next(request)
        
        # JWT 认证
        auth_header = request.headers.get("authorization", "")
        if not auth_header.startswith("Bearer "):
            return JSONResponse(
                status_code=401,
                content={"error": "Missing or invalid authorization header"}
            )
        
        token = auth_header[7:]
        try:
            user_info = app.state.token_manager.verify_token(token)
            request.state.user_info = user_info
        except HTTPException as e:
            return JSONResponse(status_code=e.status_code, content={"error": e.detail})
        
        # 限流检查
        rate_limit_key = f"rate_limit:{user_info['user_id']}"
        if not await app.state.rate_limiter.check_rate_limit(
            rate_limit_key,
            config.rate_limit_requests,
            config.rate_limit_window
        ):
            return JSONResponse(
                status_code=429,
                content={"error": "Rate limit exceeded"}
            )
        
        # 执行请求
        response = await call_next(request)
        
        # 记录指标
        duration = time.time() - start_time
        app.state.metrics.record_request(
            service="gateway",
            path=request.url.path,
            duration=duration,
            status="success" if response.status_code < 400 else "error"
        )
        
        # 添加响应头
        response.headers["X-Request-ID"] = request.state.request_id
        response.headers["X-RateLimit-Remaining"] = str(
            await app.state.rate_limiter.get_remaining(
                rate_limit_key, config.rate_limit_requests
            )
        )
        
        return response
    
    @app.get("/healthz")
    async def healthz():
        """健康检查"""
        return {
            "status": "ok",
            "services": {
                "gateway": "ok",
                "redis": "ok" if await app.state.redis.ping() else "error"
            }
        }
    
    @app.get("/metrics")
    async def metrics():
        """暴露指标"""
        return {
            "request_count": app.state.metrics.request_count,
            "error_count": app.state.metrics.error_count,
            "avg_duration": {
                k: sum(v) / len(v) if v else 0
                for k, v in app.state.metrics.request_duration.items()
            }
        }
    
    return app
```

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Optional
import asyncpg


@dataclass
class User:
    """用户模型"""
    user_id: str
    tenant_id: str
    email: str
    is_active: bool
    scopes: list[str]


@dataclass
class Tenant:
    """租户模型"""
    tenant_id: str
    name: str
    is_active: bool
    quota: dict  # 配额信息


class AuthService:
    """认证服务"""
    
    def __init__(self, db_pool: asyncpg.Pool):
        self.db_pool = db_pool
    
    async def get_user(self, user_id: str) -> Optional[User]:
        """获取用户信息"""
        async with self.db_pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT user_id, tenant_id, email, is_active, scopes
                FROM users WHERE user_id = $1
                """,
                user_id
            )
            if not row:
                return None
            return User(**dict(row))
    
    async def get_tenant(self, tenant_id: str) -> Optional[Tenant]:
        """获取租户信息"""
        async with self.db_pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT tenant_id, name, is_active, quota
                FROM tenants WHERE tenant_id = $1
                """,
                tenant_id
            )
            if not row:
                return None
            return Tenant(**dict(row))
    
    async def check_quota(self, tenant_id: str, service: str) -> bool:
        """检查配额"""
        tenant = await self.get_tenant(tenant_id)
        if not tenant or not tenant.is_active:
            return False
        
        # 检查当前使用量
        async with self.db_pool.acquire() as conn:
            usage = await conn.fetchval(
                """
                SELECT COUNT(*) FROM service_usage
                WHERE tenant_id = $1 AND service = $2
                AND created_at > NOW() - INTERVAL '1 month'
                """,
                tenant_id, service
            )
            
            quota_limit = tenant.quota.get(service, float('inf'))
            return usage < quota_limit
    
    async def record_usage(self, tenant_id: str, user_id: str, 
                          service: str, metadata: dict):
        """记录使用情况"""
        async with self.db_pool.acquire() as conn:
            await conn.execute(
                """
                INSERT INTO service_usage 
                (tenant_id, user_id, service, metadata, created_at)
                VALUES ($1, $2, $3, $4, NOW())
                """,
                tenant_id, user_id, service, metadata
            )
```

```python
# src/sts_ws_server/inference/base.py
from __future__ import annotations

from abc import ABC, abstractmethod
from dataclasses import dataclass
from typing import AsyncIterator, Any, Optional
from enum import Enum


class ModelType(Enum):
    """模型类型"""
    ASR = "asr"
    TTS = "tts"
    LLM = "llm"


@dataclass
class InferenceRequest:
    """统一的推理请求"""
    model_type: ModelType
    input_data: bytes | str | dict
    parameters: dict[str, Any]
    metadata: dict[str, Any]  # 用于追踪和日志
    timeout: float = 300.0


@dataclass
class InferenceResponse:
    """统一的推理响应"""
    output_data: bytes | str | dict
    metadata: dict[str, Any]
    latency: float
    tokens_used: Optional[int] = None


class InferenceBackend(ABC):
    """统一的推理后端接口"""
    
    @abstractmethod
    async def initialize(self) -> None:
        """初始化后端（加载模型等）"""
        pass
    
    @abstractmethod
    async def inference(self, request: InferenceRequest) -> InferenceResponse:
        """同步推理"""
        pass
    
    @abstractmethod
    async def stream_inference(
        self, request: InferenceRequest
    ) -> AsyncIterator[InferenceResponse]:
        """流式推理"""
        pass
    
    @abstractmethod
    async def health_check(self) -> dict[str, Any]:
        """健康检查"""
        pass
    
    @abstractmethod
    async def shutdown(self) -> None:
        """关闭后端"""
        pass


class InferencePool:
    """推理连接池"""
    
    def __init__(self, backend: InferenceBackend, max_concurrent: int = 2):
        self.backend = backend
        self.semaphore = asyncio.Semaphore(max_concurrent)
        self.metrics = {
            "total_requests": 0,
            "active_requests": 0,
            "failed_requests": 0,
            "total_latency": 0.0
        }
    
    async def execute(self, request: InferenceRequest) -> InferenceResponse:
        """执行推理（带并发控制）"""
        self.metrics["total_requests"] += 1
        self.metrics["active_requests"] += 1
        
        start_time = time.time()
        try:
            async with self.semaphore:
                response = await self.backend.inference(request)
            
            latency = time.time() - start_time
            self.metrics["total_latency"] += latency
            return response
            
        except Exception as e:
            self.metrics["failed_requests"] += 1
            raise
        finally:
            self.metrics["active_requests"] -= 1
    
    async def stream_execute(
        self, request: InferenceRequest
    ) -> AsyncIterator[InferenceResponse]:
        """流式执行推理"""
        self.metrics["total_requests"] += 1
        self.metrics["active_requests"] += 1
        
        try:
            async with self.semaphore:
                async for response in self.backend.stream_inference(request):
                    yield response
        except Exception as e:
            self.metrics["failed_requests"] += 1
            raise
        finally:
            self.metrics["active_requests"] -= 1
```

```python
from __future__ import annotations

import httpx
from typing import AsyncIterator

class HTTPInferenceBackend(InferenceBackend):
    """基于 HTTP 的推理后端（用于远程模型服务）"""
    
    def __init__(self, base_url: str, api_key: str = ""):
        self.base_url = base_url.rstrip("/")
        self.api_key = api_key
        self.client: Optional[httpx.AsyncClient] = None
    
    async def initialize(self) -> None:
        """初始化 HTTP 客户端"""
        self.client = httpx.AsyncClient(
            timeout=httpx.Timeout(300.0),
            limits=httpx.Limits(max_keepalive_connections=20)
        )
    
    async def inference(self, request: InferenceRequest) -> InferenceResponse:
        """HTTP 同步推理"""
        headers = {}
        if self.api_key:
            headers["Authorization"] = f"Bearer {self.api_key}"
        
        start_time = time.time()
        
        if request.model_type == ModelType.ASR:
            # ASR 请求
            response = await self.client.post(
                f"{self.base_url}/audio/transcriptions",
                headers=headers,
                files={"file": request.input_data},
                data=request.parameters
            )
        elif request.model_type == ModelType.TTS:
            # TTS 请求
            response = await self.client.post(
                f"{self.base_url}/audio/speech",
                headers=headers,
                json={**request.parameters, "input": request.input_data}
            )
        elif request.model_type == ModelType.LLM:
            # LLM 请求
            response = await self.client.post(
                f"{self.base_url}/chat/completions",
                headers=headers,
                json={**request.parameters, "messages": request.input_data}
            )
        
        response.raise_for_status()
        latency = time.time() - start_time
        
        return InferenceResponse(
            output_data=response.content if request.model_type == ModelType.TTS 
                       else response.json(),
            metadata=request.metadata,
            latency=latency
        )
    
    async def stream_inference(
        self, request: InferenceRequest
    ) -> AsyncIterator[InferenceResponse]:
        """HTTP 流式推理"""
        headers = {"Accept": "text/event-stream"}
        if self.api_key:
            headers["Authorization"] = f"Bearer {self.api_key}"
        
        async with self.client.stream(
            "POST",
            f"{self.base_url}/chat/completions",
            headers=headers,
            json={**request.parameters, "messages": request.input_data, "stream": True}
        ) as response:
            response.raise_for_status()
            async for line in response.aiter_lines():
                if line.startswith("data:"):
                    data = line[5:].strip()
                    if data and data != "[DONE]":
                        yield InferenceResponse(
                            output_data=data,
                            metadata=request.metadata,
                            latency=0.0
                        )
    
    async def health_check(self) -> dict[str, Any]:
        """健康检查"""
        try:
            response = await self.client.get(f"{self.base_url}/healthz", timeout=5.0)
            return {"status": "ok" if response.is_success else "error"}
        except Exception as e:
            return {"status": "error", "error": str(e)}
    
    async def shutdown(self) -> None:
        """关闭客户端"""
        if self.client:
            await self.client.aclose()
```

##### 2.3 **统一的重试和容错机制**

```python
# src/sts_ws_server/inference/resilience.py
from __future__ import annotations

import asyncio
from typing import Callable, TypeVar, Optional
from functools import wraps

T = TypeVar('T')


class RetryPolicy:
    """重试策略"""
    
    def __init__(
        self,
        max_retries: int = 3,
        base_delay: float = 1.0,
        max_delay: float = 60.0,
        exponential_base: float = 2.0
    ):
        self.max_retries = max_retries
        self.base_delay = base_delay
        self.max_delay = max_delay
        self.exponential_base = exponential_base
    
    def get_delay(self, attempt: int) -> float:
        """计算延迟时间（指数退避）"""
        delay = self.base_delay * (self.exponential_base ** attempt)
        return min(delay, self.max_delay)


class CircuitBreaker:
    """断路器"""
    
    def __init__(
        self,
        failure_threshold: int = 5,
        timeout: float = 60.0,
        expected_exception: type = Exception
    ):
        self.failure_threshold = failure_threshold
        self.timeout = timeout
        self.expected_exception = expected_exception
        self.failure_count = 0
        self.last_failure_time: Optional[float] = None
        self.state = "closed"  # closed, open, half_open
    
    async def call(self, func: Callable[..., T], *args, **kwargs) -> T:
        """通过断路器调用函数"""
        if self.state == "open":
            if time.time() - self.last_failure_time >= self.timeout:
                self.state = "half_open"
            else:
                raise Exception("Circuit breaker is open")
        
        try:
            result = await func(*args, **kwargs)
            if self.state == "half_open":
                self.state = "closed"
                self.failure_count = 0
            return result
            
        except self.expected_exception as e:
            self.failure_count += 1
            self.last_failure_time = time.time()
            
            if self.failure_count >= self.failure_threshold:
                self.state = "open"
            
            raise


def with_retry(policy: RetryPolicy):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            last_exception = None
            
            for attempt in range(policy.max_retries + 1):
                try:
                    return await func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    if attempt < policy.max_retries:
                        delay = policy.get_delay(attempt)
                        await asyncio.sleep(delay)
            
            raise last_exception
        return wrapper
    return decorator


class ResilientInferenceBackend:
    """带容错的推理后端包装器"""
    
    def __init__(
        self,
        backend: InferenceBackend,
        retry_policy: RetryPolicy,
        circuit_breaker: CircuitBreaker
    ):
        self.backend = backend
        self.retry_policy = retry_policy
        self.circuit_breaker = circuit_breaker
    
    @with_retry(RetryPolicy())
    async def inference(self, request: InferenceRequest) -> InferenceResponse:
        """带重试的推理"""
        return await self.circuit_breaker.call(
```

```python
user_id_var = contextvars.ContextVar('user_id', default=None)


class StructuredLogger:
    """结构化日志记录器"""
    
    def __init__(self, name: str):
        self.logger = logging.getLogger(name)
    
    def _format_message(self, level: str, message: str, **kwargs) -> dict:
        """格式化日志消息"""
        log_entry = {
            "timestamp": time.time(),
            "level": level,
            "message": message,
            "request_id": request_id_var.get(),
            "user_id": user_id_var.get(),
            **kwargs
        }
        return {k: v for k, v in log_entry.items() if v is not None}
    
    def info(self, message: str, **kwargs):
        """记录 INFO 日志"""
        self.logger.info(json.dumps(self._format_message("INFO", message, **kwargs)))
    
    def error(self, message: str, **kwargs):
        """记录 ERROR 日志"""
        self.logger.error(json.dumps(self._format_message("ERROR", message, **kwargs)))
    
    def warning(self, message: str, **kwargs):
        """记录 WARNING 日志"""
        self.logger.warning(json.dumps(self._format_message("WARNING", message, **kwargs)))
```

```python
class MetricsMiddleware:
    """指标收集中间件"""
    
    async def __call__(self, request: Request, call_next):
        start_time = time.time()
        
        try:
            response = await call_next(request)
            status = "success" if response.status_code < 400 else "error"
            
            request_count.labels(
                service=request.url.path.split('/')[1],
                method=request.method,
                status=status
            ).inc()
            
            duration = time.time() - start_time
            request_duration.labels(
                service=request.url.path.split('/')[1],
                method=request.method
            ).observe(duration)
            
            return response
            
        except Exception as e:
            error_count.labels(
                service=request.url.path.split('/')[1],
                error_type=type(e).__name__
            ).inc()
```

## 💡 关键建议

### 1. **分阶段实施**
不要尝试一次性重构所有内容，按照路线图逐步推进，每个阶段都要确保系统可用。

### 2. **保持向后兼容**
在过渡期间，新旧系统需要共存。使用特性开关（Feature Flags）来控制新功能的启用。

### 3. **充分测试**
每个阶段都要进行充分的单元测试、集成测试和压力测试，确保系统稳定性。

### 4. **监控先行**
在重构之前先建立监控体系，这样可以及时发现问题并回滚。

### 5. **文档同步**
随着架构演进，及时更新文档，包括 API 文档、部署文档和运维文档。

### 6. **团队培训**
新架构涉及新的技术栈，需要对团队进行培训，确保每个人都理解新系统。
