# ASR/LLM/TTS WebSocket 服务优化方案
## 针对 iot-mimo-ai-nokeys 语音陪伴机器人项目

**文档版本**: v2.0  
**生成日期**: 2026-09-23  
**项目背景**: 为 iot-mimo-ai-nokeys IoT 语音陪伴机器人提供 WebSocket 模型服务  
**目标模型**:
- **STT**: `kotoba-tech/kotoba-whisper-v2.0` (日语专用)
- **LLM**: `Qwen3.6-35B-A3B` (35B 参数)
- **TTS**: `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice`

---

## 📋 执行摘要

基于对现有部署架构和 iot-mimo-ai-nokeys 客户端性能分析的深入研究,我们识别出**三个最关键的性能瓶颈**:

1. **TTS 连接建立延迟** (每轮 200-500ms) - 最严重,立即可优化
2. **LLM 首 token 延迟** (缓存未充分利用,约占总延迟 30-50%)
3. **ASR Kotoba Whisper 冷启动** (首次推理 100-300ms 延迟)

**预期总收益**: 端到端延迟降低 **1.2-2.5 秒** (约 30-40%),并发能力提升 **3-5x**

- VAD 语音活动检测
- 流式 ASR 识别
- LLM 对话管理 + 工具调用

**关键延迟采样点**:
- `asr_start_ms` → `asr_end_ms`: ASR 处理时间

1. TTS 每次合成新建连接 (200-500ms 开销)
2. LLM 上下文缓存只标记 2 个点 (静态 prompt + 上一轮)
3. 记忆检索串行阻塞 LLM 调用
4. 句子切分保守,延迟首句 TTS 启动
5. 打断确认固定 1000ms

### 优化 0.1: TTS 连接池 (最高优先级!)

**问题**: 每次 TTS 合成都新建 WebSocket 连接

**当前代码** (iot-mimo-ai-nokeys):

**影响**: 每轮对话 **+200-500ms** (TCP + SSL + WebSocket 握手)

```python
@app.websocket("/tts/cosyvoice")
async def cosyvoice_realtime(websocket: WebSocket) -> None:
    if not await _accept_or_close(websocket, settings, "cosyvoice"):
        return
    
    assert active_cosyvoice is not None
    session_id = None  # 新增: 跟踪会话 ID
    started = False
    
    try:

            message = await websocket.receive()
            if message["type"] == "websocket.disconnect":
                return

            if payload is None:

                continue

                    })
                continue
            
            if not started:
                await _error(websocket, "send start before text or end")
                continue
            
            if message_type == "text":
                try:
                    text = _string_field(payload, "text", required=True)
                    if len(text or "") > settings.max_text_chars:
                        raise ValueError(f"text exceeds {settings.max_text_chars} characters")
                    
                    await _stream_tts(
                        websocket,
                        active_cosyvoice,
                        app.state.inference_limiter,
                        text or "",
                        settings.cosyvoice_tts_voice,
                        _string_field(payload, "language"),
                    )
                except ValueError as exc:
                    await _error(websocket, str(exc))
                except WebSocketDisconnect:
                    return
                except ModelBackendError as exc:
                    await _error(websocket, str(exc))
                except Exception:
                    logger.exception("CosyVoice-compatible TTS request failed")
                    await _error(websocket, "TTS inference failed")
                continue
            
            if message_type == "end":
                await websocket.send_json({"type": "done"})
                # 关键改动: 不再 return, 继续等待下一个 start
                started = False  # 重置状态,允许新一轮
                continue
            
            if message_type == "reset":
                # 新增: 显式重置会话
                started = False
                await websocket.send_json({"type": "reset_ack"})
                continue
            
            if message_type == "close":
                # 新增: 显式关闭连接
                break
            
            await _error(websocket, "expected text, end, reset, or close")
    
    except WebSocketDisconnect:
        return
    finally:
        # 可选: 延迟清理策略 (保留会话 5 分钟)
        if session_id:
            logger.info(f"Session {session_id} disconnected")
```

```python
# providers/tts/cosyvoice3.py - 新增连接池类

class TtsConnectionPool:
    """TTS WebSocket 连接池"""
    
    def __init__(self, url: str, pool_size: int = 3, ssl_context=None):
        self.url = url
        self.pool_size = pool_size
        self.ssl_context = ssl_context
        self.available: asyncio.Queue[TtsConnection] = asyncio.Queue(maxsize=pool_size)
        self.all_connections: list[TtsConnection] = []
        self._initialized = False
    
    async def initialize(self):
        """预创建连接池"""
        if self._initialized:
            return
        
        logger.info(f"Initializing TTS connection pool (size={self.pool_size})")
        for i in range(self.pool_size):
            try:
                conn = await self._create_connection()
                await self.available.put(conn)
                self.all_connections.append(conn)
            except Exception as e:
                logger.error(f"Failed to create TTS connection {i}: {e}")
        
        self._initialized = True
        logger.info(f"TTS connection pool initialized with {len(self.all_connections)} connections")
    
    async def _create_connection(self) -> 'TtsConnection':
        """创建新的 TTS 连接"""
        ws = await ws_connect(
            self.url,
            ssl=self.ssl_context,
            ping_interval=20,
            ping_timeout=20,
            max_size=None
        )
        
        # 发送 start 握手
        session_id = str(uuid.uuid4())
        await ws.send(json.dumps({"type": "start", "session_id": session_id}))
        
        response = json.loads(await ws.recv())
        if response["type"] != "audio_format":
            raise RuntimeError(f"Unexpected TTS response: {response}")
        
        return TtsConnection(ws, session_id, response)
    
    async def acquire(self) -> 'TtsConnection':
        """获取连接 (带超时和健康检查)"""
        try:
            conn = await asyncio.wait_for(self.available.get(), timeout=2.0)
            
            # 健康检查
            if conn.is_alive():
                return conn
            else:
                logger.warning(f"TTS connection {conn.session_id} is dead, recreating")
                await conn.close()
                return await self._create_connection()
        
        except asyncio.TimeoutError:
            # 池满,创建临时连接 (不会归还到池中)
            logger.warning("TTS pool exhausted, creating temporary connection")
            return await self._create_connection()
    
    async def release(self, conn: 'TtsConnection'):
        """归还连接到池中"""
        if not conn.is_alive():
            logger.warning(f"Not returning dead connection {conn.session_id}")
            return
        
        try:
            # 发送 reset 复用连接
            await conn.ws.send(json.dumps({"type": "reset"}))
            response = json.loads(await asyncio.wait_for(conn.ws.recv(), timeout=1.0))
            
            if response["type"] == "reset_ack":
                conn.last_use = time.time()
                await self.available.put(conn)
            else:
                logger.warning(f"Unexpected reset response, closing connection")
                await conn.close()
        
        except Exception as e:
            logger.error(f"Failed to reset TTS connection: {e}")
            await conn.close()
    
    async def close_all(self):
        """关闭所有连接"""
        for conn in self.all_connections:
            await conn.close()


class TtsConnection:
    """TTS 连接包装器"""
    
    def __init__(self, ws, session_id: str, audio_format: dict):
        self.ws = ws
        self.session_id = session_id
        self.audio_format = audio_format
        self.last_use = time.time()
    
    def is_alive(self) -> bool:
        """检查连接是否存活"""
        return (
            self.ws.open and 
            (time.time() - self.last_use < 300)  # 5 分钟超时
        )
    
    async def synthesize(self, text: str) -> AsyncIterator[bytes]:
        """使用连接进行合成"""
        self.last_use = time.time()
        
        # 发送文本
        await self.ws.send(json.dumps({"type": "text", "text": text}))
        
        # 接收音频
        while True:
            msg = await self.ws.recv()
            if isinstance(msg, bytes):
                yield msg
            else:
                event = json.loads(msg)
                if event["type"] == "done":
                    break
                elif event["type"] == "error":
                    raise RuntimeError(f"TTS error: {event.get('message')}")
    
    async def close(self):
        """关闭连接"""
        try:
            await self.ws.send(json.dumps({"type": "close"}))
            await self.ws.close()
        except:
            pass


# 修改原有的 CosyVoice3Provider 类使用连接池

class CosyVoice3Provider:
    def __init__(self, config: dict):
        # ... 原有初始化代码 ...
        
        # 新增: 连接池
        self._pool = TtsConnectionPool(
            url=self._url,
            pool_size=3,  # 根据并发需求调整
            ssl_context=self._ssl_context
        )
        self._pool_initialized = False
    
    async def prewarm(self, serial_number: str, trace_id: str = ""):
        """预热: 初始化连接池"""
        if not self._pool_initialized:
            await self._pool.initialize()
            self._pool_initialized = True
    
    async def synthesize_streaming(
        self,
        text_queue: asyncio.Queue[str | None],
        trace_id: str = ""
    ) -> AsyncIterator[bytes]:
        """流式合成 (使用连接池)"""
        conn = await self._pool.acquire()
        
        try:
            # 启动喂文本任务
            feed_task = asyncio.create_task(
                self._feed_texts_pooled(conn, text_queue)
            )
            
            # 接收音频流
            try:
                while True:
                    msg = await conn.ws.recv()
                    if isinstance(msg, bytes):
                        yield msg
                    else:
                        event = json.loads(msg)
                        if event["type"] == "done":
                            break
                        elif event["type"] == "error":
                            raise RuntimeError(f"TTS error: {event.get('message')}")
            
            finally:
                # 等待喂文本任务完成
                await feed_task
        
        finally:
            # 归还连接到池
            await self._pool.release(conn)
    
    async def _feed_texts_pooled(
        self, 
        conn: TtsConnection, 
        text_queue: asyncio.Queue[str | None]
    ):
        """从队列喂文本到连接"""
        while True:
            sentence = await text_queue.get()
            
            if sentence is None:
                # 发送 end 信号
                await conn.ws.send(json.dumps({"type": "end"}))
                break
            
            try:
                await conn.ws.send(json.dumps({"type": "text", "text": sentence}))
            except Exception as e:
                logger.error(f"Failed to send text to TTS: {e}")
                break
```

**问题**: 当前只标记 2 个缓存点,工具 schema 和对话历史未缓存

**当前代码** (iot-mimo-ai-nokeys):

**影响**: LLM 首 token 延迟占总延迟 **30-50%**

#### 解决方案: 3-4 层缓存标记

**实施** (iot-mimo-ai-nokeys 客户端):

```python
# providers/llm/openai_compat.py - 重构消息构建

def _build_cached_messages_v2(
    self,
    messages: list[dict],
    tools: list[dict] | None,
    dynamic_suffix: str
) -> list[dict]:
    """
    分层缓存架构:
    
    Layer 1 (Static): 静态系统提示词 + 角色设定
    Layer 2 (Semi-Static): 工具定义 (按类别缓存)
    Layer 3 (Dynamic): 对话历史前 N-2 轮
    Layer 4 (Current): 最近 2 轮 + 当前输入 (不缓存)
    """
    result = []
    
    # Layer 1: 静态层 (缓存标记 1)
    static_prompt = self._render_static_system_prompt()
    result.append({
        "role": "system",
        "content": [
            {
                "type": "text",
                "text": static_prompt,
                "cache_control": {"type": "ephemeral"}  # 标记 1
            }
        ]
    })
    
    # Layer 2: 工具层 (缓存标记 2)
    if tools:
        # 优化: 只下发相关工具 (减少 token 数)
        relevant_tools = self._filter_relevant_tools(tools, messages[-1] if messages else {})
        
        result.append({
            "role": "system",
            "content": [
                {
                    "type": "text",
                    "text": json.dumps(relevant_tools, ensure_ascii=False),
                    "cache_control": {"type": "ephemeral"}  # 标记 2
                }
            ]
        })
    
    # Layer 3: 历史层 (缓存标记 3)
    # 保留除最近 2 轮外的全部历史
    if len(messages) > 4:
        history_messages = messages[:-2]
        
        # 将历史渲染为紧凑格式
        history_text = "\n".join([
            f"{m['role']}: {m['content']}" 
            for m in history_messages
        ])
        
        result.append({
            "role": "system",
            "content": [
                {
                    "type": "text",
                    "text": f"[对话历史]\n{history_text}",
                    "cache_control": {"type": "ephemeral"}  # 标记 3
                }
            ]
        })
    
    # Layer 4: 当前轮 (不缓存,包含瞬态信息)
    recent_messages = messages[-2:] if len(messages) >= 2 else messages
    for msg in recent_messages:
        result.append({
            "role": msg["role"],
            "content": msg["content"]
        })
    
    # 动态尾注 (时间戳等) - 附加到最后一条消息
    if result and dynamic_suffix:
        last_content = result[-1]["content"]
        if isinstance(last_content, str):
            result[-1]["content"] = f"{last_content}\n\n{dynamic_suffix}"
        else:
            # 如果是列表,附加到最后一个 text block
            last_content.append({"type": "text", "text": f"\n\n{dynamic_suffix}"})
    
    return result

def _filter_relevant_tools(
    self, 
    all_tools: list[dict], 
    last_user_message: dict
) -> list[dict]:
    """
    根据最后一条用户消息预测相关工具
    
    简单策略: 关键词匹配
    高级策略: 使用轻量级 embedding 模型
    """
    user_text = last_user_message.get("content", "").lower()
    
    # 关键词映射 (示例)
    tool_keywords = {
        "get_weather": ["天气", "温度", "下雨", "weather"],
        "search_web": ["搜索", "查找", "search", "find"],
        "set_timer": ["定时", "提醒", "timer", "remind"],
        "play_music": ["音乐", "歌曲", "music", "song"],
        # ... 其他工具
    }
    
    relevant_tools = []
    for tool in all_tools:
        tool_name = tool.get("function", {}).get("name", "")
        keywords = tool_keywords.get(tool_name, [])
        
        # 如果用户输入包含关键词,认为相关
        if any(kw in user_text for kw in keywords):
            relevant_tools.append(tool)
    
    # 如果没有匹配,返回所有工具 (保守策略)
    if not relevant_tools:
        return all_tools
    
    # 最多返回 10 个工具 (避免 token 爆炸)
    return relevant_tools[:10]
```

### 优化 0.3: 记忆检索并发化

```python
# utils/sentence_splitter.py - 添加预测性切分

class PredictiveSentenceSplitter:
    """预测性句子切分器"""
    
    def __init__(self):
        self.buffer = ""
        self.last_chunk_time = 0
        self.llm_paused_threshold = 0.3  # 300ms 停顿
    
    def feed(self, chunk: str) -> list[str]:
        """
        喂入 LLM chunk,返回完整句子列表
        
        策略:
        1. 明确句子边界 (。?!) → 立即切分
        2. 超过 40 字 + 有逗号 → 预切分
        3. LLM 停顿 300ms + 有标点 → 切分
        """
        self.buffer += chunk
        sentences = []
        
        while self.buffer:
            # 策略 1: 明确边界
            match = re.search(r'[。?!]', self.buffer)
            if match:
                pos = match.end()
                sentences.append(self.buffer[:pos].strip())
                self.buffer = self.buffer[pos:]
                continue
            
            # 策略 2: 超长 + 逗号 → 预切分
            if len(self.buffer) > 40 and ',' in self.buffer:
                pos = self.buffer.rfind(',', 0, 50)
                if pos > 20:
                    sentences.append(self.buffer[:pos+1].strip())
                    self.buffer = self.buffer[pos+1:]
                    continue
            
            # 策略 3: LLM 停顿 + 标点 → 切分
            current_time = time.time()
            if (current_time - self.last_chunk_time) > self.llm_paused_threshold:
                # LLM 停顿了,检查是否有标点
                punctuation_pos = max(
                    self.buffer.rfind('，'),
                    self.buffer.rfind(','),
                    self.buffer.rfind('、')
                )
                if punctuation_pos > 10:  # 至少 10 个字
                    sentences.append(self.buffer[:punctuation_pos+1].strip())
                    self.buffer = self.buffer[punctuation_pos+1:]
                    continue
            
            # 没有可切分的,等待更多 chunk
            break
        
        self.last_chunk_time = time.time()
        return sentences
    
    def flush(self) -> str:
        """刷新缓冲区,返回剩余文本"""
        result = self.buffer.strip()
        self.buffer = ""
        return result
```

```python
# core/pipeline.py - 修改打断检测

class PipelineChatEngine:
    def __init__(self, ...):
        # 双阈值配置
        self._interrupt_threshold_low = 0.4   # 低阈值: 开始怀疑
        self._interrupt_threshold_high = 0.7  # 高阈值: 立即确认
        self._interrupt_confirm_duration_ms = 1000  # 低阈值确认时长
        self._interrupt_fast_confirm_ms = 200       # 高阈值快速确认
    
    def _check_interrupt(self, vad_result):
        """检测打断 (双阈值策略)"""
        probability = vad_result.probability
        elapsed = time.time() - self._interrupt_start_time
        
        # 高阈值: 立即确认 (强信号)
        if probability >= self._interrupt_threshold_high:
            if elapsed >= self._interrupt_fast_confirm_ms / 1000:
                logger.info(f"Fast interrupt confirmed (prob={probability:.2f})")
                self._confirm_interrupt()
                return
        
        # 低阈值: 延迟确认 (弱信号,需等待)
        elif probability >= self._interrupt_threshold_low:
            if elapsed >= self._interrupt_confirm_duration_ms / 1000:
                logger.info(f"Slow interrupt confirmed (prob={probability:.2f})")
                self._confirm_interrupt()
                return
        
        # 未达到阈值: 取消打断检测
        else:
            if self._state == ConversationState.INTERRUPT_DETECTING:
                self._state = self._prev_state
                self._interrupt_start_time = 0
```

```python
# dialogue.py - 添加批量写入器

class DialogueBatchWriter:
    """对话批量写入器 (降低 Redis RTT)"""
    
    def __init__(self, redis_client, flush_interval: float = 0.5):
        self.redis_client = redis_client
        self.flush_interval = flush_interval
        self.buffer: list[Message] = []
        self.lock = asyncio.Lock()
        self._flush_task: asyncio.Task | None = None
    
    async def add(self, msg: Message):
        """添加消息到缓冲区"""
        async with self.lock:
            self.buffer.append(msg)
            
            # 启动刷新任务 (如果未运行)
            if self._flush_task is None or self._flush_task.done():
                self._flush_task = asyncio.create_task(self._flush_loop())
    
    async def _flush_loop(self):
        """定期刷新缓冲区"""
        await asyncio.sleep(self.flush_interval)
        
        async with self.lock:
            if self.buffer:
                await self._flush_batch(self.buffer.copy())
                self.buffer.clear()
    
    async def _flush_batch(self, messages: list[Message]):
        """批量写入 Redis"""
        if not messages:
            return
        
        # 按 serial_number 分组
        by_serial: dict[str, list[Message]] = {}
        for msg in messages:
            serial = msg.metadata.get("serial_number", "default")
            by_serial.setdefault(serial, []).append(msg)
        
        # 批量写入
        async with self.redis_client.pipeline() as pipe:
            for serial, msgs in by_serial.items():
                key = f"dialogue:{serial}"
                
                # 批量 lpush
                items = [msg.to_redis_item() for msg in msgs]
                for item in items:
                    pipe.lpush(key, item)
                
                # trim 和 expire
                pipe.ltrim(key, 0, 99)  # 保留最近 100 条
                pipe.expire(key, 86400)  # 24 小时过期
            
            await pipe.execute()
    
    async def flush_now(self):
        """立即刷新 (用于关键时刻)"""
        async with self.lock:
            if self.buffer:
                await self._flush_batch(self.buffer.copy())
                self.buffer.clear()


# 在 Dialogue 类中集成

class Dialogue:
    def __init__(self, ...):
        # ... 原有初始化 ...
        
        # 批量写入器
        self._batch_writer = DialogueBatchWriter(
            redis_client=redis_client,
            flush_interval=0.5  # 500ms 刷新一次
        )
    
    def add_message(self, msg: Message):
        """添加消息 (异步写入)"""
        self.messages.append(msg)
        
        # 异步写入 Redis (不等待)
        asyncio.create_task(self._batch_writer.add(msg))
    
    async def flush_to_redis(self):
        """立即刷新到 Redis (用于对话结束等关键时刻)"""
        await self._batch_writer.flush_now()
```

```python
class OpusCodecMixin:

        self._encode_executor = ThreadPoolExecutor(max_workers=2)

        flush: bool = False
    ) -> list[bytes]:

        return await loop.run_in_executor(

            self._pcm_to_opus,
            pcm,
            flush
        )
    
    async def _send_audio_frames_async(self, pcm_chunks: list[bytes]):

        encode_tasks = []
        
        for i, pcm in enumerate(pcm_chunks):
            is_last = (i == len(pcm_chunks) - 1)
            task = asyncio.create_task(
                self._pcm_to_opus_async(pcm, flush=is_last)
            )
            encode_tasks.append(task)
        
        # 等待所有编码完成
        encoded_frames_list = await asyncio.gather(*encode_tasks)
        
        # 发送所有帧
        for encoded_frames in encoded_frames_list:
            for frame in encoded_frames:
                await self._websocket.send(frame)
```

```python
# src/sts_ws_server/asr_batch.py - 新增批处理引擎

class BatchedASREngine:
    """ASR 动态批处理引擎"""
    
    def __init__(
        self, 
        backend: ASRBackend,
        max_batch_size: int = 8,
        max_wait_ms: int = 50
    ):
        self.backend = backend
        self.max_batch_size = max_batch_size
        self.max_wait_ms = max_wait_ms
        self.queue: asyncio.Queue = asyncio.Queue()
        self._worker_task = None
    
    async def start(self):
        """启动批处理工作线程"""
        self._worker_task = asyncio.create_task(self._batch_worker())
    
    async def transcribe(
        self, 
        session_id: str, 
        audio: bytes, 
        language: str | None
    ) -> Transcript:
        """提交音频到批处理队列"""
        future = asyncio.Future()
        await self.queue.put((session_id, audio, language, future))
        return await future
    
    async def _batch_worker(self):
        """批处理工作线程"""
        while True:
            batch = []
            deadline = asyncio.get_event_loop().time() + self.max_wait_ms / 1000
            
            # 收集批次
            while len(batch) < self.max_batch_size:
                timeout = max(0, deadline - asyncio.get_event_loop().time())
                try:
                    item = await asyncio.wait_for(
                        self.queue.get(), 
                        timeout=timeout
                    )
                    batch.append(item)
                except asyncio.TimeoutError:
                    break
            
            if batch:
                await self._process_batch(batch)
    
    async def _process_batch(self, batch: list):
        """批量推理"""
        session_ids, audios, languages, futures = zip(*batch)
        
        try:
            # Padding 到相同长度
            max_len = max(len(a) for a in audios)
            padded_audios = [
                a + b'\x00' * (max_len - len(a)) 
                for a in audios
            ]
            
            # GPU 批量推理 (需要后端支持)
            if hasattr(self.backend, 'transcribe_batch'):
                results = await self.backend.transcribe_batch(
                    padded_audios, 
                    languages
                )
            else:
                # 回退: 逐个推理
                results = []
                for audio, lang in zip(audios, languages):
                    result = await self.backend.transcribe(audio, lang)
                    results.append(result)
            
            # 返回结果
            for future, result in zip(futures, results):
                if not future.done():
                    future.set_result(result)
        
        except Exception as e:
            # 批量失败,返回错误
            for future in futures:
                if not future.done():
                    future.set_exception(e)
```

### 优化 2.3: TTS 流式生成优化

**问题**: 当前 TTS 可能是句级合成,不是真正流式

**影响**: 首帧延迟

#### 解决方案: Chunk-by-Chunk 生成

需要在 TTS 模型服务端实现真正的流式生成 (类似 vLLM 的流式推理)

**参考实现** (TTS 模型服务):

```python
class StreamingTtsEngine:
    def __init__(self):
        self.model = load_qwen_tts_model()
        self.vocoder = load_vocoder()
        
        # 流式配置
        self.chunk_size = 20  # 每次生成 20 帧 (~240ms)
        self.overlap = 2      # 2 帧 overlap,平滑拼接
    
    async def synthesize_streaming(self, text: str) -> AsyncIterator[bytes]:
        """真正的流式 TTS"""
        # 文本 → 音素序列
        phonemes = self.g2p(text)
        
        # 分块生成 mel 谱
        mel_chunks = self.model.inference_streaming(
            phonemes,
            chunk_size=self.chunk_size,
            overlap=self.overlap
        )
        
        # 流式 vocoder
        prev_chunk = None
        async for mel_chunk in mel_chunks:
            # 拼接 overlap 部分
            if prev_chunk is not None:
                mel_chunk = self._blend_overlap(prev_chunk, mel_chunk)
            
            # Griffin-Lim 或 HiFiGAN 实时 vocoding
            audio_chunk = await asyncio.to_thread(
                self.vocoder.inference,
                mel_chunk
            )
            
            # 立即发送
            yield audio_chunk.tobytes()
            prev_chunk = mel_chunk
```

**预期收益**:
- ✅ 首帧延迟: 800ms → **150-250ms**
- ✅ 更流畅的音频输出

## 💡 关键建议

### 1. 分阶段实施,逐步验证

不要试图一次性重构所有内容。每个阶段完成后,充分测试并收集数据,再进入下一阶段。

### 2. 优先快速见效项

阶段 0 的优化影响大、实施快,建议优先实施,快速看到效果。

### 3. 保持向后兼容

在过渡期间,新旧系统需要共存。使用特性开关 (Feature Flags) 控制新功能启用。

### 4. 监控先行

在优化之前建立完整的监控体系,这样可以量化优化效果并及时发现问题。

### 5. 针对性优化

不要盲目追求"最佳实践",而要基于实际瓶颈进行针对性优化。例如:
- Kotoba Whisper 是日语专用模型,不需要多语言优化
- Qwen 35B 是大模型,缓存优化比量化更重要
- IoT 设备并发不高,吞吐量优化可以后置

### 6. 客户端配合

很多优化需要客户端 (iot-mimo-ai-nokeys) 配合,确保与客户端团队充分沟通。
