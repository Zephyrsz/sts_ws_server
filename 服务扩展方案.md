## 当前架构分析

你的系统是一个语音服务WebSocket服务器，包含：

**核心服务**：

- ASR (语音识别) - 内置VAD，支持Faster-Whisper/Kotoba本地推理或OpenAI兼容API
- TTS (语音合成) - Qwen3-TTS和CosyVoice，通过OpenAI兼容API调用
- LLM WebSocket Bridge - 转发Chat Completions到本地Ornith模型

**当前部署**：

- Nginx作为TLS网关 (18443端口)
- 每个服务使用systemd管理
- 并发限制：`MAX_CONCURRENT_REQUESTS=1` (Qwen TTS), `=2` (ASR)
- GPU使用：GPU 0上运行Qwen3-TTS (vLLM)

**核心问题**：

1. 单GPU负载集中，GPU 0承载所有TTS推理
2. 并发限制过低，无法支持大量并行连接
3. 缺少智能负载均衡和请求路由
4. 没有水平扩展机制

## 多GPU扩展架构设计

### 方案一：GPU亲和性 + 多进程部署（推荐用于2-4 GPU）

这个方案适合你当前的L20-8-hk服务器（8张GPU卡）。

#### 架构图

```
外部客户端 (wss://...)
    ↓
Nginx (18443) - TLS终止 + Bearer认证
    ↓ (upstream轮询)
    ├─→ TTS-GPU0 (172.19.0.1:18100) → vLLM-GPU0 (127.0.0.1:8091)
    ├─→ TTS-GPU1 (172.19.0.1:18101) → vLLM-GPU1 (127.0.0.1:8191)
    ├─→ TTS-GPU2 (172.19.0.1:18102) → vLLM-GPU2 (127.0.0.1:8291)
    └─→ TTS-GPU3 (172.19.0.1:18103) → vLLM-GPU3 (127.0.0.1:8391)
    
ASR服务 (独立扩展)
    ├─→ ASR-GPU4 (172.19.0.1:18200) → 本地Kotoba/Faster-Whisper
    └─→ ASR-GPU5 (172.19.0.1:18201) → 本地Kotoba/Faster-Whisper
```

#### 核心设计原则

**1. GPU隔离**：每个进程绑定专用GPU，避免显存竞争

```bash
# GPU 0-3: TTS服务（每GPU一个vLLM + 一个WSS适配器）
CUDA_VISIBLE_DEVICES=0 vllm serve ...
CUDA_VISIBLE_DEVICES=1 vllm serve ...

# GPU 4-5: ASR服务
CUDA_VISIBLE_DEVICES=4 python -m sts_ws_server.app
CUDA_VISIBLE_DEVICES=5 python -m sts_ws_server.app

# GPU 6-7: 预留给LLM或其他服务
```

**2. Nginx智能路由**：基于least_conn实现会话亲和性

```nginx
# /etc/nginx/conf.d/multi-gpu-tts.conf
upstream tts_qwen_backend {
    least_conn;  # 最少连接数负载均衡
    
    server 172.19.0.1:18100 max_fails=3 fail_timeout=30s;
    server 172.19.0.1:18101 max_fails=3 fail_timeout=30s;
    server 172.19.0.1:18102 max_fails=3 fail_timeout=30s;
    server 172.19.0.1:18103 max_fails=3 fail_timeout=30s;
    
    keepalive 32;
}

upstream asr_backend {
    least_conn;
    
    server 172.19.0.1:18200 max_fails=3 fail_timeout=30s;
    server 172.19.0.1:18201 max_fails=3 fail_timeout=30s;
    
    keepalive 16;
}

server {
    listen 18443 ssl;
    
    # TTS路由
    location = /tts/v1/realtime {
        proxy_pass http://tts_qwen_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Authorization $http_authorization;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Request-ID $request_id;
        
        # WebSocket超时
        proxy_connect_timeout 10s;
        proxy_send_timeout 3600s;
        proxy_read_timeout 3600s;
        
        # 禁用缓冲
        proxy_buffering off;
        proxy_request_buffering off;
        
        # 限流 (每个IP，20并发，100 req/min)
        limit_conn perip 20;
        limit_req zone=perip burst=20 nodelay;
    }
    
    # ASR路由
    location = /asr/v1/realtime {
        proxy_pass http://asr_backend;
        # ... 相同配置
    }
}

# 限流配置
limit_req_zone $binary_remote_addr zone=perip:10m rate=100r/m;
limit_conn_zone $binary_remote_addr zone=perip:10m;
```

**4. 自动化部署脚本**

```bash
#!/bin/bash
# deploy-multi-gpu.sh - 多GPU部署脚本

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
BASE_DIR="/app/sts_ws_server"

# GPU配置
TTS_GPU_LIST=(0 1 2 3)      # TTS使用GPU 0-3
ASR_GPU_LIST=(4 5)          # ASR使用GPU 4-5
TTS_BASE_PORT=18100         # WSS适配器起始端口
TTS_VLLM_BASE_PORT=8091     # vLLM起始端口
ASR_BASE_PORT=18200

log() {
    echo "[$(date +'%Y-%m-%d %H:%M:%S')] $*"
}

check_gpu() {
    if ! command -v nvidia-smi &>/dev/null; then
        log "ERROR: nvidia-smi not found"
        exit 1
    fi
    
    local gpu_count
    gpu_count=$(nvidia-smi --list-gpus | wc -l)
    log "Detected $gpu_count GPUs"
    
    if [ "$gpu_count" -lt 6 ]; then
        log "WARNING: Less than 6 GPUs available"
    fi
}

deploy_tts_instance() {
    local gpu_id=$1
    local wss_port=$((TTS_BASE_PORT + gpu_id))
    local vllm_port=$((TTS_VLLM_BASE_PORT + gpu_id * 100))
    
    log "Deploying TTS on GPU $gpu_id (WSS:$wss_port, vLLM:$vllm_port)"
    
    # 启动vLLM模型服务
    sudo systemctl enable "qwen3-tts-vllm@${gpu_id}.service"
    sudo systemctl restart "qwen3-tts-vllm@${gpu_id}.service"
    
    # 等待模型加载
    log "Waiting for vLLM GPU$gpu_id to be ready..."
    for i in {1..60}; do
        if curl -fsS "http://127.0.0.1:${vllm_port}/v1/models" &>/dev/null; then
            log "vLLM GPU$gpu_id is ready"
            break
        fi
        [ $i -eq 60 ] && { log "ERROR: vLLM GPU$gpu_id failed to start"; exit 1; }
        sleep 2
    done
    
    # 启动WSS适配器
    sudo systemctl enable "sts-ws-qwen@${gpu_id}.service"
    sudo systemctl restart "sts-ws-qwen@${gpu_id}.service"
    
    # 验证健康
    sleep 3
    if curl -fsS "http://172.19.0.1:${wss_port}/healthz" | grep -q "ok"; then
        log "TTS GPU$gpu_id adapter is healthy"
    else
        log "WARNING: TTS GPU$gpu_id adapter health check failed"
    fi
}

deploy_asr_instance() {
    local gpu_id=$1
    local idx=$2
    local port=$((ASR_BASE_PORT + idx))
    
    log "Deploying ASR on GPU $gpu_id (port:$port)"
    
    sudo systemctl enable "sts-ws-asr@${gpu_id}.service"
    sudo systemctl restart "sts-ws-asr@${gpu_id}.service"
    
    sleep 5
    if curl -fsS "http://172.19.0.1:${port}/healthz" | grep -q "ok"; then
        log "ASR GPU$gpu_id is healthy"
    else
        log "WARNING: ASR GPU$gpu_id health check failed"
    fi
}

reload_nginx() {
    log "Reloading Nginx configuration..."
    sudo nginx -t && sudo systemctl reload nginx
}

show_status() {
    log "\n=== Service Status ==="
    
    echo -e "\nTTS Services:"
    for gpu_id in "${TTS_GPU_LIST[@]}"; do
        echo -n "  GPU$gpu_id vLLM: "
        systemctl is-active "qwen3-tts-vllm@${gpu_id}.service" || echo "inactive"
        echo -n "  GPU$gpu_id WSS:  "
        systemctl is-active "sts-ws-qwen@${gpu_id}.service" || echo "inactive"
    done
    
    echo -e "\nASR Services:"
    for idx in "${!ASR_GPU_LIST[@]}"; do
        local gpu_id="${ASR_GPU_LIST[$idx]}"
        echo -n "  GPU$gpu_id: "
        systemctl is-active "sts-ws-asr@${gpu_id}.service" || echo "inactive"
    done
    
    echo -e "\n=== GPU Memory Usage ==="
    nvidia-smi --query-gpu=index,name,memory.used,memory.total --format=csv
}

main() {
    log "Starting multi-GPU deployment..."
    
    check_gpu
    
    # 部署TTS实例
    for gpu_id in "${TTS_GPU_LIST[@]}"; do
        deploy_tts_instance "$gpu_id"
    done
    
    # 部署ASR实例
    for idx in "${!ASR_GPU_LIST[@]}"; do
        deploy_asr_instance "${ASR_GPU_LIST[$idx]}" "$idx"
    done
    
    # 重载Nginx
    reload_nginx
    
    # 显示状态
    show_status
    
    log "Deployment completed!"
}

case "${1:-deploy}" in
    deploy)
        main
        ;;
    status)
        show_status
        ;;
    stop)
        log "Stopping all services..."
        for gpu_id in "${TTS_GPU_LIST[@]}"; do
            sudo systemctl stop "sts-ws-qwen@${gpu_id}.service" || true
            sudo systemctl stop "qwen3-tts-vllm@${gpu_id}.service" || true
        done
        for gpu_id in "${ASR_GPU_LIST[@]}"; do
            sudo systemctl stop "sts-ws-asr@${gpu_id}.service" || true
        done
        ;;
    *)
        echo "Usage: $0 {deploy|status|stop}"
        exit 1
        ;;
esac
```

### 方案二：Redis队列 + 动态调度（推荐用于高并发场景）

适合需要更精细控制、支持数百个并发连接的场景。

#### 核心组件

**1. 中心化请求分发器**

```python
# src/sts_ws_server/dispatcher/scheduler.py
import asyncio
import time
from dataclasses import dataclass
from typing import Dict, List
import aioredis
import logging

logger = logging.getLogger(__name__)

@dataclass
class GPUWorker:
    """GPU工作节点"""
    worker_id: str
    gpu_id: int
    service_url: str
    max_concurrent: int
    current_load: int = 0
    last_heartbeat: float = 0
    is_healthy: bool = True

class IntelligentScheduler:
    """智能GPU调度器"""
    
    def __init__(self, redis_url: str = "redis://localhost:6379"):
        self.redis = None
        self.redis_url = redis_url
        self.workers: Dict[str, GPUWorker] = {}
        self.request_queue = asyncio.Queue()
        
    async def initialize(self):
        """初始化调度器"""
        self.redis = await aioredis.from_url(
            self.redis_url,
            encoding="utf-8",
            decode_responses=True
        )
        asyncio.create_task(self._worker_discovery())
        asyncio.create_task(self._health_monitor())
        
    async def _worker_discovery(self):
        """服务发现：从Redis获取可用worker"""
        while True:
            try:
                # 从Redis获取注册的worker
                worker_keys = await self.redis.keys("worker:*")
                
                for key in worker_keys:
                    worker_data = await self.redis.hgetall(key)
                    worker_id = key.split(":")[1]
                    
                    if worker_id not in self.workers:
                        self.workers[worker_id] = GPUWorker(
                            worker_id=worker_id,
                            gpu_id=int(worker_data["gpu_id"]),
                            service_url=worker_data["service_url"],
                            max_concurrent=int(worker_data["max_concurrent"]),
                            current_load=int(worker_data.get("current_load", 0)),
                            last_heartbeat=float(worker_data.get("last_heartbeat", 0))
                        )
                        logger.info(f"Discovered worker: {worker_id} on GPU {worker_data['gpu_id']}")
                        
            except Exception as e:
                logger.error(f"Worker discovery error: {e}")
                
            await asyncio.sleep(5)
    
    async def _health_monitor(self):
        """健康监控：标记不健康的worker"""
        while True:
            current_time = time.time()
            
            for worker_id, worker in list(self.workers.items()):
                # 30秒无心跳视为不健康
                if current_time - worker.last_heartbeat > 30:
                    if worker.is_healthy:
                        logger.warning(f"Worker {worker_id} is unhealthy (no heartbeat)")
                        worker.is_healthy = False
                        
                # 清理长时间不健康的worker
                if current_time - worker.last_heartbeat > 120:
                    logger.info(f"Removing dead worker: {worker_id}")
                    del self.workers[worker_id]
                    
            await asyncio.sleep(10)
    
    def select_worker(self, service_type: str = "tts") -> GPUWorker | None:
        """选择最优worker（负载最低且健康）"""
        available = [
            w for w in self.workers.values()
            if w.is_healthy and w.current_load < w.max_concurrent
        ]
        
        if not available:
            return None
            
        # 选择负载率最低的worker
        return min(available, key=lambda w: w.current_load / w.max_concurrent)
    
    async def assign_request(self, request_id: str) -> str | None:
        """分配请求到最优worker"""
        worker = self.select_worker()
        
        if not worker:
            logger.warning("No available workers for request")
            return None
            
        # 更新负载
        worker.current_load += 1
        await self.redis.hincrby(f"worker:{worker.worker_id}", "current_load", 1)
        
        # 记录分配
        await self.redis.setex(
            f"request:{request_id}",
            3600,  # 1小时过期
            worker.worker_id
        )
        
        logger.info(f"Assigned request {request_id} to worker {worker.worker_id} (GPU {worker.gpu_id})")
        return worker.service_url
    
    async def release_request(self, request_id: str):
        """释放请求，减少worker负载"""
        worker_id = await self.redis.get(f"request:{request_id}")
        
        if worker_id and worker_id in self.workers:
            worker = self.workers[worker_id]
            worker.current_load = max(0, worker.current_load - 1)
            await self.redis.hincrby(f"worker:{worker_id}", "current_load", -1)
            logger.debug(f"Released request {request_id} from worker {worker_id}")
```

**2. Worker注册与心跳**

```python
# src/sts_ws_server/dispatcher/worker.py
import asyncio
import time
import socket
from dataclasses import dataclass
import aioredis

@dataclass
class WorkerConfig:
    worker_id: str
    gpu_id: int
    service_url: str
    max_concurrent: int
    redis_url: str = "redis://localhost:6379"

class WorkerRegistry:
    """Worker注册和心跳管理"""
    
    def __init__(self, config: WorkerConfig):
        self.config = config
        self.redis = None
        self.is_running = False
        
    async def initialize(self):
        """初始化Redis连接"""
        self.redis = await aioredis.from_url(
            self.config.redis_url,
            encoding="utf-8",
            decode_responses=True
        )
        
    async def register(self):
        """注册worker到Redis"""
        await self.redis.hset(
            f"worker:{self.config.worker_id}",
            mapping={
                "gpu_id": self.config.gpu_id,
                "service_url": self.config.service_url,
                "max_concurrent": self.config.max_concurrent,
                "current_load": 0,
                "last_heartbeat": time.time(),
                "hostname": socket.gethostname()
            }
        )
        logger.info(f"Registered worker {self.config.worker_id} on GPU {self.config.gpu_id}")
        
    async def send_heartbeat(self):
        """发送心跳"""
        while self.is_running:
            try:
                await self.redis.hset(
                    f"worker:{self.config.worker_id}",
                    "last_heartbeat",
                    time.time()
                )
                await asyncio.sleep(10)  # 每10秒发送一次
            except Exception as e:
                logger.error(f"Heartbeat error: {e}")
                await asyncio.sleep(5)
                
    async def start(self):
        """启动worker"""
        await self.initialize()
        await self.register()
        self.is_running = True
        asyncio.create_task(self.send_heartbeat())
        
    async def stop(self):
        """停止worker并清理"""
        self.is_running = False
        await self.redis.delete(f"worker:{self.config.worker_id}")
        await self.redis.close()
```

**3. 网关集成调度器**

```python
# src/sts_ws_server/gateway_with_scheduler.py
from fastapi import FastAPI, WebSocket, HTTPException
from sts_ws_server.dispatcher.scheduler import IntelligentScheduler
import httpx
import uuid

app = FastAPI()
scheduler = IntelligentScheduler()

@app.on_event("startup")
async def startup():
    await scheduler.initialize()

@app.websocket("/tts/v1/realtime")
async def tts_gateway(websocket: WebSocket):
    await websocket.accept()
    request_id = str(uuid.uuid4())
    
    try:
        # 选择worker
        worker_url = await scheduler.assign_request(request_id)
        
        if not worker_url:
            await websocket.send_json({"type": "error", "message": "No available GPU workers"})
            await websocket.close()
            return
        
        # 代理WebSocket连接到选定的worker
        async with httpx.AsyncClient() as client:
            async with client.stream(
                "GET",
                worker_url.replace("http://", "ws://") + "/tts/v1/realtime",
                headers=dict(websocket.headers),
                timeout=None
            ) as upstream:
                # 双向转发消息
                async def forward_to_upstream():
                    while True:
                        message = await websocket.receive()
                        # 转发到upstream worker
                        
                async def forward_to_client():
                    async for chunk in upstream.aiter_bytes():
                        await websocket.send_bytes(chunk)
                        
                await asyncio.gather(
                    forward_to_upstream(),
                    forward_to_client()
                )
                
    finally:
        await scheduler.release_request(request_id)
```
